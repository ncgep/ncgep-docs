# Asset origin

Canonical identity is **not** a ticker symbol.

| Asset | Canonical origin |
|---|---|
| Dalet | Core |
| Diamonds | Gaming Domain |
| Gaming NFTs | Gaming (network + class + token) |
| Soulbound assets | Gaming; non-exportable by default across Domains |
| Enterprise entities/claims | Enterprise network context; not automatic tokens |

Cross-game Diamonds do **not** require IBC (same Gaming Domain). Cross-Domain
movement requires future IBC (or an explicitly approved design) and must preserve
origin semantics for clients.

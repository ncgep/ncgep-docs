# Core vs Domains

| | Core | Domain |
|---|---|---|
| Purpose | Ecosystem settlement / Dalet origin | Specialized application protocols |
| Example | `ncgep-core` | Gaming, Enterprise |
| Bech32 | `ncgep*` reserved | Domain-specific HRPs (e.g. `ngame*`, `nent*`) |
| Security | Independent PoS / curated bootstrap | Independent; may differ (e.g. consortium) |
| EVM | OFF on Core | Not mandatory |

Organization registries, credentials, and game engines are **not** Core features.
